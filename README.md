# 🚀 Baidu-OCR  
### Warm-up Task — ERNIE AI Developer Challenge (Baidu Hackathon)

This repository contains my solution for the **Warm-up Task** of the *Baidu ERNIE AI Developer Challenge Hackathon*.  
The goal of this challenge was to **process PDFs**, extract their content using OCR/LLM processing, and automatically generate a **static website** (HTML + CSS).

---

## 📌 Project Overview
- Read and parse a PDF document.
- Split it into manageable text fragments.
- Send each fragment to an LLM for processing.
- Collect and merge the responses.
- Generate a final static website from the processed content.

All of this is orchestrated through a custom **Python scripts** that automates the entire flow from PDF → AI → HTML/CSS.

---

## 🧩 Tech Stack
- **Python**
- **Baidu ERNIE API** for LLM processing
- **Baidu PaddleOCR API** for pdf to text processing
- **HTML + CSS** for the final static site
